# 当前记忆与交接

**按需读取：** 接手、需求漂移、记忆冲突或记录结构需整理时使用。普通继续开发若现行记录已清楚，可直接沿用，不每轮重读本指南。

章节导航：缺少入口 → `先复用，再补缺口`；记录过长/缺项 → `当前记录应该保留什么`；改向 → `变更想法时`；恢复开发 → `接手步骤`。

适用边界：只维护一份当前记录；历史快照需与当前指令核对，修改时间不决定需求优先级。记忆提供意图和导航，代码与对应版本的验证仍需按本轮影响核实。

## 先复用，再补缺口

先读适用的项目 `AGENTS.md` / `CLAUDE.md` 和它指向的当前记录。入口不明时再用 README 或文档索引定位，不默认读取全部项目文档。已有任务系统/当前记录能承担这些信息时继续用它；不要另建一套平行真相。

没有约定时，按需采用以下结构；后两类只在内容足够复杂时出现：

```text
AGENTS.md / CLAUDE.md   项目命令、约束、当前记录入口；不复制需求正文
README.md              如何使用、启动和验证产品
docs/CURRENT.md         当前目标、有效决定、导航、证据、下一步
docs/decisions/         少量重要且有取舍的长期决定（可选）
docs/archive/           已完成阶段的长记录（可选）
```

入口文件各自服从宿主指令体系。核心过程来自同一技能，项目事实来自同一记录。若已有 `docs/PROJECT.md`、issue 或其他路径，直接用原位置；不要为了模板改名。

使用 `context-save`、`context-restore`、`checkpoint` 或 `handoff` 时，快照记录来源项目、分支、日期和当前记录路径，需求正文尽量引用原记录。恢复前核对当前指令与有效决定；较新的存档时间不代表其中的旧需求重新生效。快照保留历史状态，项目当前记录仍只有一个。

## 当前记录应该保留什么

- **本轮目标与边界：** 要解决的问题、用户可见结果、暂缓内容；需求变化修订当前表述。
- **验收标准：** 观察什么才算完成；实现、效果、真实使用分别有哪些证据要求。
- **当前决定：** 标记有效、候选、已替代；写决定、理由、来源日期/任务和适用范围。旧方向注明由哪条取代，不让两者并列生效。
- **代码导航：** 本轮入口、关键模块、数据流/契约、相关测试和运行方式。指向实际文件/符号，比大段源码复述更有用。
- **推进约定：** 适用的验证层级、汇报节点、质量样本、已明确的成本上限和失败停止条件。个人习惯仅写此项目适用部分。
- **最近验证：** 命令或手工步骤、结果、覆盖内容、代码版本/工作树、环境、证据位置和未验证项。旧通过记录保留历史身份，不冒充当前通过。
- **下一步：** 未完成项、阻塞需要的具体输入，以及下一条可执行动作。

把当前目标、有效决定、本轮导航、证据缺口和下一步放在记录开头，保持能快速读完；长日志和历史推演留在既有位置并链接。不要为 TL;DR 新建第二份当前计划，也不机械搬走仍有效的约束。

接手先读当前摘要；只有本轮问题需要追溯，才读取相应历史或详细契约。摘要遗漏关键验收、发生截断或发现矛盾时，补读相关原文。源码仍是实现事实的依据；若项目与文档不符，先查相关差异，不一律以文档覆盖代码或让整个记录作废。

## 变更想法时

“先改成 B，A 暂时不要了”属于明确改向：修订本轮目标，将冲突的 A 标为已替代/暂缓，保留其余约束。“能不能试试 B”通常先作为候选或试验问题，说明是否会占用本轮交付；不要自动实施完整 B。

真正冲突且无法自行判定时，用一个具体决策问题解决；无关工作仍可继续。不能根据文档修改时间就认定哪条意图有效，优先当前明确指令及其适用范围，再看来源和决定状态。

每个有意义的目标/验收变化递增 `goal_revision`（启用脚本时）；不要只在末尾追加一条新想法，留下旧目标仍然有效。纯操作进展不改变目标版本。

## 接手步骤

1. 读项目入口与当前记录，简短复述本轮目标、有效决定及最重要缺口。需要脚本时运行 `brief`，其输出有长度上限；若被截断，直接读取所需段落。
2. 查当前分支、提交、未提交差异和相关运行环境；沿导航看需要修改的源码、契约与测试。仅在索引缺失、明显过期或影响确实跨模块时扩大范围。
3. 核实最近验证是否仍对应当前输入。已启用脚本可运行 `gate`，它只读证据，不执行测试。不要把接手变成无条件全量回归。
4. 选择下一块可交付结果并继续已授权工作。当前记录不是新的审批点。

交接前刷新当前记录。记录工作树状态与已知有效版本，不擅自提交、推送、重置或清理用户改动。失败试验写明假设、观察和失败原因，保留可复用证据，避免下一个 agent 重试同一路线。
